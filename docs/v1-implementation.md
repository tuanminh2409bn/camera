## Ranh giới tin cậy và bất biến

1. Browser không có credential camera/Air/MediaMTX. Mọi request kiểm user đang active và quyền hiện tại, không tin quyền gửi từ client.
2. Login dùng Argon2id; admin cần TOTP chống replay. TOTP secret mã hóa, session random chỉ lưu hash, cookie HttpOnly/Secure/SameSite và hạn hữu hạn. Mutation yêu cầu Origin đúng và CSRF token. Băm mật khẩu giới hạn4 tác vụ đồng thời; giới hạn login theo IP và tài khoản lưu PostgreSQL, cho phép nhiều người cùng NAT.
3. Media admission giữ reservation trước khi gọi WHEP native. PostgreSQL transaction/advisory lock tuần tự hóa quota; reserved/active/revoking đều giữ suất tới khi xác nhận native đã đóng. Yêu cầu thứ 201 bị từ chối.
4. Native WHEP Location chứa session **secret**, không phải ID Control API. API giữ Location riêng tư và trả resource ID của ứng dụng. DELETE native dùng để thu hồi; `appSession` query dùng đối chiếu API sessions khi kết quả POST bị mất hoặc process restart.
5. Disable/logout/kick đưa phiên vào revoking, cắt native và reconcile lại; không giải phóng suất chỉ vì timeout. Không lộ cổng WHEP/Control API trực tiếp ra public.
6. Playback chỉ gọi địa chỉ Air được cấu hình cố định qua tunnel; không nhận URL/filename tùy ý. Kiểm quyền trước mỗi stream, giới hạn đồng thời và duration, truyền streaming có cancel/backpressure, không ghi file server.
7. Recording desired state lưu trước, observed state đọc từ Air, reconcile khi kết nối trở lại. Không tự bật ghi sau disk pause hoặc auth latch của supervisor.
8. API, DB, WHEP và tunnel endpoint bind loopback. Chỉ Caddy HTTPS và media UDP cần public khi deploy đã được duyệt. Secrets trong file0600, không log request body/header/token.
